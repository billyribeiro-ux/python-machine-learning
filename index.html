How this course works

  • Narrated & deep. Each lesson goes concept → mechanism → implementation → "build a better one" → pitfalls. We never stop at "call this function."
  • Copy-to-local execution. The code panes are full Monaco editors with Copy and Download .py buttons. Run everything against a real local Python install — the only way TA-Lib, vectorbt, Numba, and XGBoost actually work. See Module 0 for setup.
  • Provider-agnostic data. Examples use free Yahoo Finance through a DataProvider abstraction, so switching to Alpaca, Polygon, IBKR, or crypto (CCXT) is a one-line change.
  • Tested. A real pytest suite validates indicators against references/TA-Lib and computes verified strategy stats from multiple indicators with custom settings.
  • Navigate with the sidebar or the Previous / Next buttons on every lesson. Your progress is saved in your browser.
🧱 The QuantLab package

Alongside the lessons you build a reusable Python package, quantlab/: a normalized data layer, a from-scratch indicator library, a DuckDB market-data warehouse, and (in later modules) a backtest + stats engine and an ML pipeline. The course is the construction of a production-grade quant toolkit.
