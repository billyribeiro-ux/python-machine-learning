Module 6 · Indicators

pandas-ta & Custom Studies

pandas-ta adds 130+ indicators directly onto DataFrames and lets you declare whole "studies" (named bundles of indicators) in one call. We use it for breadth and convenience — and learn exactly where it diverges from TA-Lib so your backtests stay reproducible.

1. The DataFrame-native approach

Where TA-Lib speaks raw arrays, pandas-ta attaches a .ta accessor to any DataFrame: df.ta.rsi(length=14) returns an indexed Series; df.ta.macd() returns a multi-column frame. It's pure Python (no C library to install), which makes it frictionless for exploration — at the cost of speed on hot paths.

2. Strategy objects: declare a bundle once

pandas-ta's Strategy lets you name a set of indicators with custom settings and apply them all at once with df.ta.strategy(...) — even multi-threaded. This is the pandas-ta expression of "combine multiple indicators with custom settings."

⚠️ Definitions diverge — pick one source of truth

pandas-ta and TA-Lib don't always agree to the last decimal. RSI smoothing, MACD defaults, and Bollinger population-vs-sample standard deviation can differ. That's fine until a backtest's results silently depend on which library computed the indicator. Rule: for any indicator a strategy actually trades on, pin a single implementation (ours, TA-Lib, or pandas-ta) and test against it — so results are reproducible regardless of library versions.

3. Runnable: pandas-ta with a graceful fallback

pandas-ta currently ships wheels only for Python ≥ 3.12, so on 3.11 it may not install. The script below demonstrates the API when present and otherwise computes the same indicators via our registry — proving the concepts transfer regardless of library availability.

🧱 When to reach for which

pandas-ta for breadth and quick exploration (no C dependency, huge catalog, DataFrame-native). TA-Lib for canonical, fast, widely-trusted definitions. Our registry / NumPy / Polars / Numba for production hot paths, multi-symbol scale, path-dependent indicators, and total control. A principal engineer uses all three behind one uniform interface — which is exactly what Module 7 builds.

🛠️ Try it

If you're on Python 3.12+, install pandas-ta and build a ta.Strategy with five indicators of your choosing, then compare its RSI column to quantlab.indicators.rsi on the same data. Note any divergence and decide which you'd standardize on — then write a one-line test asserting your chosen source stays put.
