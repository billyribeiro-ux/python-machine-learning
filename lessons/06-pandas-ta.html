Module 6 · Indicators

pandas-ta & Custom Studies

pandas-ta adds 130+ indicators directly onto DataFrames and lets you compose whole 'studies'. We use it for breadth and learn where it complements (and where it diverges from) TA-Lib.

🚧 Full lesson in progress

The course is being written module-by-module for maximum depth. This lesson's detailed outline is below so you can see exactly what it will cover — and the underlying quantlab package code it builds on already exists and is tested. Modules 0–4 are complete and runnable; work through those first.

What this lesson will cover

The DataFrame extension API

df.ta.rsi(), df.ta.macd(), and the .ta.strategy() runner that computes a named bundle of indicators in one call.

Building a custom Strategy object

Declaring a reusable set of indicators with custom settings as a ta.Strategy, then applying it across a universe.

Multiprocessing & performance notes

When pandas-ta's convenience costs you speed, and how to fall back to our Polars/NumPy implementations for hot paths.

TA-Lib vs pandas-ta divergences

Subtle definitional differences (e.g. RSI smoothing, MACD defaults) and how to pick a single source of truth so backtests are reproducible.

Composing into the QuantLab pipeline

Normalizing pandas-ta output back into our schema and feeding it to the backtest engine.

🧱 Already in the repo

The reusable building blocks for this module live in the quantlab/ package (data layer, indicators, backtest + stats engine, strategy combiner) and are exercised by the tests/ suite. The lesson narration will show you how they were built and how to extend them.
