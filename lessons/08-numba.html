Module 8 · Indicators

Numba: Path-Dependent Speed

Some indicators are inherently sequential — Supertrend, trailing stops, parabolic SAR — where each bar depends on the last. Numba JIT-compiles these Python loops to C speed, beating even clever vectorization.

What this lesson will cover

When vectorization loses

Path-dependent recurrences can't be expressed as a single array op without O(n^2) tricks. The honest answer is a loop — just a fast one.

@njit, nopython, and the type system

Writing Numba-friendly code: typed arrays in/out, no Python objects, why the first call is slow (compilation) and the rest are C-fast.

Building Supertrend & a trailing-stop ATR

A real path-dependent indicator from scratch, JIT-compiled, validated against a slow reference.

parallel=True and guvectorize

Parallelizing across symbols with prange, and writing generalized ufuncs that broadcast like NumPy.

Plugging Numba indicators into the registry

Numba-backed compute() behind the Module 7 interface, so callers never know it's compiled.
