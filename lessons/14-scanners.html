Module 14 · Putting It Together

Multi-Symbol Scanners

Combine the data lake, Polars, and the indicator library into fast scanners that rank a universe for day-trading and swing setups.

🚧 Full lesson in progress

The course is being written module-by-module for maximum depth. This lesson's detailed outline is below so you can see exactly what it will cover — and the underlying quantlab package code it builds on already exists and is tested. Modules 0–4 are complete and runnable; work through those first.

What this lesson will cover

Scanner architecture

DuckDB lake -> Polars .over('symbol') indicators -> ranking/filtering -> alerts. Build on code/m4_windows_sql.py.

Swing-trade scans

Pullbacks-in-uptrend, breakouts, relative strength vs SPY (extending the Module 4 RS join).

Intraday/day-trade scans

Gap-ups, opening-range breakouts, VWAP reclaims on 1m/5m bars; the data-provider intraday limits and how to handle them.

Ranking & cross-sectional normalization

Z-scoring features across the universe so 'top 20' means something comparable.

Alerting & scheduling

Turning a scan into a repeatable job that writes results and notifies you.
