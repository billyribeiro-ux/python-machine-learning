Optuna: Optimize Everything

One optimizer for both worlds: tune indicator/strategy settings AND ML hyperparameters, with pruning, multi-objective trade-offs, and persisted studies.

🚧 Full lesson in progress

The course is being written module-by-module for maximum depth. This lesson's detailed outline is below so you can see exactly what it will cover — and the underlying quantlab package code it builds on already exists and is tested. Modules 0–4 are complete and runnable; work through those first.

What this lesson will cover

The study/trial model

Define an objective(trial) that builds params and returns a score (e.g. walk-forward Sharpe). Reuse ComboParams as the search space.

Samplers & pruning

TPE sampling, median pruning to kill bad trials early, and why random search is a strong baseline.

Multi-objective optimization

Maximize return AND minimize drawdown simultaneously; reading the Pareto front instead of one 'best'.

Optimizing strategy settings

Sweep the combo strategy's fast/slow/RSI/z thresholds — the principled version of the Module 9 grid.

Persistence & overfitting guards

SQLite-backed studies for resumability, and validating the chosen params truly out-of-sample.
