Module 16 · Putting It Together

Streamlit Trading Dashboard

Tie everything together into an interactive app: a live scanner, a backtest explorer, ML predictions, and QuantStats tearsheets — all driven by the quantlab package.

🚧 Full lesson in progress

The course is being written module-by-module for maximum depth. This lesson's detailed outline is below so you can see exactly what it will cover — and the underlying quantlab package code it builds on already exists and is tested. Modules 0–4 are complete and runnable; work through those first.

What this lesson will cover

Streamlit fundamentals

Widgets, layout, and st.cache_data for fast, reactive apps without re-fetching data.

The scanner page

Pick a universe and settings, run the Module 14 scan, show a ranked, sortable table with sparklines.

The backtest explorer

Sliders for the combo strategy's settings -> live equity curve, drawdown, and the stats bundle from quantlab.backtest.

The ML page

Show model predictions, feature importance/SHAP, and predicted-vs-realized performance.

Deployment

Caching, secrets for real data providers, and running it locally or on Streamlit Community Cloud.

🧱 Already in the repo

The reusable building blocks for this module live in the quantlab/ package (data layer, indicators, backtest + stats engine, strategy combiner) and are exercised by the tests/ suite. The lesson narration will show you how they were built and how to extend them.
