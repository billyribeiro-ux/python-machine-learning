What this lesson will cover

Features & the leak-free frame

Reuse the Module 2 feature template (quantlab.utils.forward_returns) to build X and a labeled y with no look-ahead.

Triple-barrier labeling

Lopez de Prado's method: label by which of {profit-take, stop-loss, time-out} is hit first — far better than naive forward-return signs.

Pipelines & preprocessing

StandardScaler + model in a Pipeline so scaling is fit only on training folds (a subtle but critical leak source).

Purged & embargoed K-fold

Why plain KFold leaks in time series, and how purging/embargo fixes it.

Evaluating a trading model

Classification metrics vs actual backtested PnL — accuracy is not edge.
